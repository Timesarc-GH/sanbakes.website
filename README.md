# San Bakes website

Premium bilingual preorder storefront for San Bakes, Keelkattalai, Chennai.

## Included

- English and Tamil presentation
- 29-product launch menu with 75 selectable options across brownies, boxes, Brownie Tins, Brownie Tubs, millet tea cakes, birthday brownie cakes, cupcakes and gifting
- Dedicated Menu & Pricing, Our Standard, Gifting & Corporate, Delivery & Pickup, FAQ, Policies and Preorder pages
- Recommended pack/quantity variants for every menu item, carried into the WhatsApp enquiry summary
- Owner-selected V5 selling prices applied directly to 74 options; Bespoke Corporate Gifting remains quotation-only
- No-index owner reference page for approved V5 prices and separate operational checks
- Local enquiry basket and structured WhatsApp handoff
- Preorder, pickup, 20 km delivery, cancellation and allergen guidance
- Owner-provided and retouched product imagery, story video and Open Graph artwork
- Transactional checkout intentionally disabled while FSSAI, entity, recipe and payment details are pending

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
npm test
```

All 74 populated V5 prices are approved website selling prices. Bespoke Corporate Gifting remains individually priced because its branding, packaging and fulfilment scope varies.

The domains `sanbakes.com`, `sanbakes.in` and `sanbakes.co.in` have been purchased for two years and are still being registered. They are not connected to this private preview yet.
